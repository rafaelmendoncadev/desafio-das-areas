1. Conteúdo teórico

Conversão de unidades de medida de área.

Atenção: área é uma medida ao quadrado

Nas medidas de comprimento, cada passo vale 10. Nas medidas de área, cada passo vale 100, porque estamos trabalhando com unidades quadradas.

UnidadeNomeRelação com a unidade vizinha
km²quilômetro quadrado× 100 para hm²
hm²hectômetro quadrado× 100 para dam²
dam²decâmetro quadrado× 100 para m²
m²metro quadrado× 100 para dm²
dm²decímetro quadrado× 100 para cm²
cm²centímetro quadrado× 100 para mm²

➡️ Para a direita

Multiplique por 100 a cada casa.

Ex.: m² → dm² = ×100.

⬅️ Para a esquerda

Divida por 100 a cada casa.

Ex.: m² → dam² = ÷100.

🧠 Dica

Conte quantos “saltos” existem entre as unidades. Dois saltos significam ×10.000 ou ÷10.000.

Regra geral: em conversões de área, cada deslocamento na escala corresponde a duas casas na vírgula (×100 ou ÷100).

2. Exemplos resolvidos

Observe o caminho antes de responder.

Exemplo 1

4 m² → dm²

  1. m² → dm² = 1 salto.
  2. 1 salto = ×100.
  3. 4 × 100 = 400.
Resposta: 400 dm²

Exemplo 2

2,5 m² → cm²

  1. m² → dm² → cm² = 2 saltos.
  2. 2 saltos = ×10.000.
  3. 2,5 × 10.000 = 25.000.
Resposta: 25.000 cm²

Exemplo 3

7.200 cm² → m²

  1. cm² → dm² → m² = 2 saltos.
  2. 2 saltos = ÷10.000.
  3. 7.200 ÷ 10.000 = 0,72.
Resposta: 0,72 m²

Exemplo 4

0,6 km² → hm²

  1. km² → hm² = 1 salto.
  2. 1 salto = ×100.
  3. 0,6 × 100 = 60.
Resposta: 60 hm²

Exemplo 5

3.500 dam² → km²

  1. dam² → hm² → km² = 2 saltos.
  2. 2 saltos = ÷10.000.
  3. 3.500 ÷ 10.000 = 0,35.
Resposta: 0,35 km²

Exemplo 6

0,08 m² → cm²

  1. m² → dm² → cm² = 2 saltos.
  2. 2 saltos = ×10.000.
  3. 0,08 × 10.000 = 800.
Resposta: 800 cm²
